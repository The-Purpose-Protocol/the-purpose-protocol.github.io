What is GitHub?

Before you can document anything, you need to understand the two tools everyone confuses: Git and GitHub.

Git is the tool. GitHub is the place.

Git is a version control system that runs on your machine. It records snapshots of your files so you can travel back in time, branch off experiments, and collaborate without overwriting each other's work.

GitHub is a cloud platform that hosts Git repositories. It adds a social layer — profiles, issues, pull requests, code review, automation, and a portfolio that recruiters can actually read.

Git

  • Runs locally on your machine
  • Tracks changes & history
  • Works completely offline
  • No account required

GitHub

  • Hosts repositories in the cloud
  • Issues, PRs, reviews, Actions
  • Collaboration & visibility
  • Free for public & private work

In cybersecurity, this matters because your methodology, your findings and your remediation advice all need a traceable history. Git gives you that traceability. GitHub gives it a home.

bash · first-time setup 
# 1. Tell Git who you are
git config --global user.name  "Your Name"
git config --global user.email "you@example.com"

# 2. Create a repository in the current folder
git init

# 3. Stage everything and commit
git add .
git commit -m "chore: initial commit"

# 4. Connect to GitHub and push
git remote add origin git@github.com:USER/REPO.git
git branch -M main
git push -u origin main

Pro tip for security folks

Always authenticate with an SSH key or a personal access token — never with your password. GitHub removed password authentication for Git operations in 2021.

Starter kit

Everything you need to begin

Copy these commands, run them once, and you're ready to start documenting.

bash · install git 
# Debian / Ubuntu / Kali
sudo apt update && sudo apt install -y git

# Fedora / RHEL
sudo dnf install -y git

# macOS (Homebrew)
brew install git

# Verify
git --version
bash · generate an SSH key 
# Ed25519 is the modern default
ssh-keygen -t ed25519 -C "you@example.com"

# Start the agent
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

# Print the public key, then paste it into
# GitHub → Settings → SSH and GPG keys
cat ~/.ssh/id_ed25519.pub
